# Burned: Miami Idle

An idle game about a burned spy rebuilding in Miami. Single static page, no build step.

## Run locally
Open `index.html` in a browser, or serve the folder:

    npx serve .

## Deploy
Import this repo on Vercel. Framework preset: **Other**. No build command, output directory is the repo root.

Progress is saved in the browser (localStorage). Use *export save* / *import save* in the footer to move it between browsers.
